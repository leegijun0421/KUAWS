# frontend-flow — 요구사항

> 상태: 구현 완료 (2026-09-27). 와이어프레임 `docs/WIREFRAMES.md`, 코드 `frontend/src/`.

## 목표

단톡방 대화 붙여넣기부터 공유까지 5분 안에 끝나는, 설명 가능한 그룹 일정 화면을 만든다.

## 기능 요구사항

| ID | 요구사항 | 수용 기준 |
|----|----------|-----------|
| FF-1 | 도시 선택 | 화이트리스트(파리·타이베이)만 버튼으로, 장소 수 표시 |
| FF-2 | 대화 입력 | 단톡방 붙여넣기(예시 5종 버튼) 또는 한 명씩 입력 |
| FF-3 | 슬라이더 5축 확인·수정 | 멤버 카드마다 5축, AI 확신 < 0.6 인 축은 노란 칸 + 후속 질문. 축을 임의로 늘리지 않음(절단 3) |
| FF-4 | 조건 확인 | 대화에서 뽑은 제외 조건·꼭 가고 싶은 곳을 칩으로, 잘못 읽었으면 삭제 |
| FF-5 | 결과 요약 | 코스 브리핑, 그룹 최저 만족도 + 멤버별 만족도, 주의·제외 안내 |
| FF-6 | 일정 타임라인 | 일차 탭, 스톱 카드(시각·유형·그룹 적합도·실패 위험 신호등) |
| FF-7 | 경로 카드 | 실제 편성 출발·도착 시각(현지), 환승·요금, 경고 배지, 경치 대안 토글 |
| FF-8 | 약관 표기 | 운영기관 이름·URL(응답 값 그대로) + “경로 데이터 © Google”, 지도 표시 시 Google 로고 |
| FF-9 | 상세 | 스톱 클릭 → 멤버별 만족도·실패 위험 근거·Google 지도 링크 |
| FF-10 | 로딩·오류 | 실경로 조회 중 단계 메시지, API 오류는 문구로 표시(입력 보존) |
| FF-11 | 모바일 | 420px 폭에서 가로 스크롤 없이 동작 |

## 범위 밖

- 지도 위 실제 경로 모양(폴리라인) — 순서만 점선으로 표시(E2 스트레치, 본선)
- 다국어 UI
