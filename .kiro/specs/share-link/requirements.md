# share-link — 요구사항

> 상태: 구현 완료 (2026-09-27). 코드 `backend/share/`, `backend/planner/replay.py`, `frontend/src/pages/SharePage.tsx`.

## 목표

특정 플랫폼에 종속되지 않는 링크 하나로 일정을 공유하되, Google 약관(경로 저장 금지)을 지킨다.

## 기능 요구사항

| ID | 요구사항 | 수용 기준 |
|----|----------|-----------|
| SL-1 | 링크 생성 | `POST /api/share` → `{planId, url, expiresAt}`, URL 은 `/s/<planId>` |
| SL-2 | 약관 준수 저장 | 저장 내용은 일정 요청 입력 + 일차별 Place ID 순서뿐. 경로·시각 미저장 |
| SL-3 | 열람 시 재계산 | 같은 순서로 경로만 다시 조회해 같은 장소 순서를 보여준다 |
| SL-4 | 만료 | 30일(좌표 임시 캐싱 한도와 동일). 만료·없는 링크는 404 |
| SL-5 | 플랫폼 비종속 | 카카오·인스타 SDK 없음. 클립보드 복사만 |

## 범위 밖

- 공유받은 사람의 편집·투표 (본선 검토)
- 계정·권한 — 링크를 아는 사람은 누구나 열람
