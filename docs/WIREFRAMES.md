# 화면 3종 와이어프레임 (입력 / 일정 / 상세)

> W0 태스크 산출물. 구현은 이 구조를 그대로 따른다(`frontend/src/`). 모바일 폭(≈420px) 기준.
> 실제 구현 화면 캡처는 `docs/images/screen_*.png`.

## 1. 입력 — 도시·날짜 + 단톡방 대화

```
┌──────────────────────────────────────┐
│        AI 그룹 여행 플래너             │
│           모두의 여행                  │
│ 단톡방 대화를 붙여넣으면 아무도 소외되지   │
│ 않는 일정을 실제 시간표에 맞춰 만들어요    │
├──────────────────────────────────────┤
│ 1. 어디로, 언제 가나요?                 │
│  [■ 파리 · 135곳] [□ 타이베이 · 135곳]  │ ← 도시 선택 = 화이트리스트 드롭다운 역할
│  출발일 [2026-10-15]   일수 [2일 ▼]     │
├──────────────────────────────────────┤
│ 2. 다들 어떤 여행을 원하나요?            │
│  (단톡방 붙여넣기 | 한 명씩 적기)         │
│  (예시: 파리·먹방+알레르기) (예시: …)    │
│ ┌──────────────────────────────────┐ │
│ │[민지] [오후 8:02] 루브르는 꼭 가자   │ │
│ │[서연] [오후 8:03] 빵집 투어!        │ │
│ └──────────────────────────────────┘ │
│  [      대화에서 취향 읽기        ]     │
└──────────────────────────────────────┘
        │
        ▼  취향 확인(입력의 2단계)
┌──────────────────────────────────────┐
│ 3. 이렇게 이해했어요 — 맞나요?           │
│ ┌ 대화에서 찾은 조건 ────────────────┐ │
│ │ ⭐ 꼭 가기: Musée du Louvre   ✕     │ │
│ │ 🚫 이름에 “seafood…” 들어간 식당 ✕ │ │
│ └───────────────────────────────────┘ │
│ ┌ 민지 ────────────┐ ┌ 서연 ───────────┐│
│ │활동량   ──●──────│ │…               ││ ← 슬라이더 5축(절단 3)
│ │풍경  ⚠ 확인해 주세요│ │                ││ ← AI 확신 < 0.6 = 노란 칸 + 질문
│ │ 자연 ─────●── 도심│ │                ││
│ └──────────────────┘ └────────────────┘│
│  [ ✨ 3명 모두를 위한 일정 만들기 ]       │ (하단 고정)
└──────────────────────────────────────┘
```

## 3. 상세 — 스톱을 누르면 하단 시트

```
┌──────────────────────────────────────┐
│ 미술관·전시 · 09:30–11:30          ✕  │
│ Musée du Louvre                        │
│ 멤버별 만족도                            │
│  민지 █████████ 100%                   │
│  서연 ██████    62%                    │
│  도윤 █████     55%                    │
│  · 가장 잘 맞는 사람: 민지               │
│  · 가장 아쉬운 사람: 도윤                │
│ 실패 위험 12%                           │
│  · 환승 연결 여유 4분                    │
│  · 영업 종료까지 여유 50분               │
│  (객관 지표만 사용 · 유명하다고 감점 안 함) │
│        Google 지도에서 보기              │
└──────────────────────────────────────┘
```

## 공유 링크 열람 (`/s/<id>`)

일정 화면과 같고, 상단에 “친구가 공유한 일정이에요 · 우리 일정 만들기” 한 줄이 붙는다.
