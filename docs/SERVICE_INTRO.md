# 서비스 소개 문구 (대중평가·제출용)

> 대중평가(5점)는 일반인이 투표한다. 기술 용어 없이, 누구나 겪은 장면으로 시작한다.

## 한 줄

**단톡방 대화를 붙여넣으면, 아무도 소외되지 않는 여행 일정이 실제 지하철 시간표에 맞춰 나옵니다.**

## 세 줄 (카드·썸네일)

- “나는 미술관, 너는 맛집, 쟤는 공원” — 단톡방이 정리해 주지 못한 취향을 AI 가 대신 읽어요.
- 평균 말고 **가장 아쉬운 친구**의 만족도를 먼저 챙겨서 장소를 고릅니다.
- 몇 시 몇 분 지하철을 타고, 어디서 갈아타는지까지 **진짜 시간표**로 알려드려요.

## 소개 문단 (150자 내외)

친구 여행 계획, 단톡방에서 며칠씩 걸리죠. ‘모두의 여행’은 대화를 붙여넣기만 하면 사람마다의 취향과
알레르기 같은 조건을 읽고, 누구 한 명만 손해 보지 않도록 일정을 짭니다. 이동은 실제 대중교통
시간표로 계산하고, 링크 하나로 바로 공유할 수 있어요. 지금은 파리와 타이베이를 지원합니다.

## 데모 장면 설명 (발표·영상 자막용)

1. 파리 여행 단톡방 대화를 붙여넣는다 → 세 사람의 취향 카드가 뜬다(한 명은 갑각류 알레르기).
2. “확실하지 않은 취향”만 슬라이더로 한 번 확인한다.
3. 일정 생성 → 루브르(꼭 가고 싶은 곳)부터 시작, 점심·저녁 식당이 12시·18시에 들어간다.
4. 이동 카드에 “11:38 출발 · 11:46 도착, 환승 1회” — 지어낸 게 아니라 실제 시간표.
5. “가장 아쉬운 사람도 76% 만족” — 평균이 아니라 최저 만족도를 올린 결과.
6. 링크 공유 → 친구 폰에서 같은 일정이 열린다.

## 피해야 할 표현

- “완벽한 일정”, “모든 도시” — 지원 도시는 검증한 2곳뿐이다.
- “실시간 혼잡도 반영” — 쓰지 않는다(설계 원칙).
- “AI 가 경로를 만든다” — 경로는 AI 가 아니라 실제 교통 데이터다. 이게 차별점이다.
