## 판정 기준

| 판정 | 뜻 |
|------|----|
| ok | 5축 모두 사람이 보기에 납득된다 |
| minor | 한 축이 분명히 어긋난다(나머지는 납득) |
| fail | 두 축 이상 어긋나거나 방향이 반대다 |

통과 기준: ok ≥ 80% 이고 fail ≤ 2건.

## 체계적 오차 — 알고 쓰는 한계

1. **명소의 pace 과소(2건).** 잠깐 보고 지나가는 조형물·작은 건물도 수집 단계의 카테고리 기본
   체류시간(명소 90분)을 근거로 "여유롭게"로 매겨졌다. 원인은 프롬프트가 아니라 입력값이다.
   → 본선: 수집 단계에서 유형별이 아닌 장소별 체류시간을 쓰거나, 프롬프트에 "체류시간이 기본값일 수
   있음"을 알린다.
2. **체험형 명소의 food_priority 과소(1건).** 와인 저장고 체험을 일반 명소로 봤다.
3. **crowd_tolerance 는 대부분 0.5 근처.** 메타데이터에 혼잡 신호가 없어서다. 설계 원칙("실시간
   혼잡도 미사용")상 의도된 결과이며 confidence 가 낮게 기록돼 매칭 가중치에도 반영된다.
