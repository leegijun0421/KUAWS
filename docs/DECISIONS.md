# 의사결정 기록 (ADR)

결정이 바뀔 때마다 맨 위에 추가한다. 지우지 않는다.
"왜 그렇게 만들었는가"를 발표 때 설명할 근거가 된다.

형식:

```
## YYYY-MM-DD — <제목>
결정: 
이유: 
대안과 기각 사유: 
```

## 2026-08-23 — Kiro 협업은 Git + 파일 소유권 방식으로 한다

결정: 실시간 동시 편집 대신 모듈별 파일 소유권 + 짧은 브랜치 + `.kiro/` 공유로 협업한다.
이유: Kiro에는 실시간 공동 편집 기능이 없다. 에이전트는 한 작업에 파일 10개 이상을
건드리므로, 경계를 명시하지 않으면 5인 팀에서 충돌이 폭증한다.
대안과 기각 사유: Kiro Crew — 6주 예선에 새 인프라 세팅은 오버엔지니어링. 본선에서 재검토.

## 2026-08-21 — 익명 기능 제외

결정: 모든 의견에 작성자를 표시한다.
이유: 그룹 조율 서비스에서 익명은 책임 소재를 흐리고, 멤버별 만족도 표시 기능과 충돌한다.

## 2026-08-21 — 실시간 현황 데이터 제외

결정: 혼잡도 등 실시간 데이터를 쓰지 않는다.
이유: 데이터 확보가 불안정하고, 6주 안에 신뢰성 있게 통합하기 어렵다.
객관 지표 기반 실패 확률로 대체한다.

## 2026-08-21 — 데모 도시는 부산

결정: 부산.
이유: 대중교통 밀집 도심이라 경로 상세 기능이 드러난다.
대안과 기각 사유: 제주 — 차량 의존적 구조라 대중교통 경로 차별점이 죽는다.
