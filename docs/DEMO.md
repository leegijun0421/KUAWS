> W4 "[W4] 데모 시나리오 3종 사전 리허설 + 화면 녹화 fallback", "[W4] 데모 영상 촬영 (3분)".
> Google 약관상 결과(경로 응답)를 파일로 저장해 둘 수 없으므로, **실제로 돌린 화면을 녹화**해 둔다.
> 발표 중 API 장애·네트워크 불안정 시 이 영상으로 대체한다.

## 시나리오 3종

| # | 입력 (`mocks/chats/`) | 도시·일수 | 보여줄 것 |
|---|----------------------|-----------|-----------|
| A | `01_paris_foodie_allergy.txt` | 파리 · 2일 | **메인.** 루브르(must_visit) 첫 스톱, 12·18시 식사, 해산물 식당 제외, 실제 편성 시각·환승, 상세 모달 |
| B | `03_paris_conflict.txt` | 파리 · 1일 | 정반대 두 사람 → maximin(“가장 아쉬운 사람도 N%”), 경치 대안 경로 토글 |
| C | `04_taipei_night_market.txt` | 타이베이 · 1일 | 두 번째 도시(확장성), 땅콩 알레르기, 운영기관 표기, **링크 공유 → 열람** |

## 사전 점검 (발표 전날 · 당일 아침)

- [ ] `.env` 에 `ROUTING_MOCK`, `LLM_OFFLINE` 이 비어 있다(모의 경로 금지)
- [ ] `GET /api/planner/cities` 의 `dataSource` 가 두 도시 모두 `collected`
- [ ] 수집 좌표 만료일(`data/processed/pois/<city>/meta_<city>.json` 의 `coord_expires_at`, 10/27) 이전
- [ ] 출발일은 **오늘 기준 100일 이내**(Routes API 제한). 기본값(오늘+18일)을 그대로 쓴다
- [ ] 키 A 가 발표 장소 네트워크 IP 에서 동작하는지(IP 제한!) — 아니면 핫스팟 또는 녹화본 사용
- [ ] 브라우저 확대 100%, 알림 끄기, 창 1280×800 이상
- [ ] 녹화본 3개(`Claude outputs/demo/A.webm`…)를 발표 PC 바탕화면에 복사

## 녹화 방법 (자동)

```powershell
# PowerShell, C:\project\KUAWS — 처음 한 번
pip install playwright
python -m playwright install chromium

# 터미널 1
uvicorn backend.main:app --port 8000
# 터미널 2
cd frontend; npm run dev
# 터미널 3
python scripts/record_demo.py          # A·B·C 3종 녹화 + 단계별 소요 시간 출력
```

스크립트가 화면 하단에 자막을 띄우며 진행하므로 녹화본 자체가 설명을 담는다.
출력된 “취향 추출 / 일정 생성” 소요 시간을 아래 리허설 기록에 옮긴다.

## 3분 영상 대본 (자막 = `scripts/record_demo.py` 캡션과 동일)

| 시간 | 화면 | 자막 / 내레이션 |
|------|------|-----------------|
| 0:00–0:15 | 제목 | 친구 여행 계획, 단톡방에서 며칠씩 걸리죠. “모두의 여행”은 대화만 붙여넣으면 끝납니다. |
| 0:15–0:40 | A 입력 → 취향 카드 | 대화를 사람별로 나눠 5가지 취향과 알레르기·꼭 가고 싶은 곳을 읽습니다. 확실하지 않은 것만 슬라이더로 한 번 묻습니다. |
| 0:40–1:20 | A 결과 | 루브르부터 시작, 12시·18시에 식당, 해산물 식당은 제외. 이동은 AI 가 지어낸 게 아니라 **실제 대중교통 시간표** — 몇 시 몇 분 출발, 어디서 환승. |
| 1:20–1:40 | A 상세 모달 | 장소마다 누가 만족하고 누가 아쉬운지, 환승 여유·영업 종료 같은 객관 지표로 본 실패 위험. |
| 1:40–2:15 | B | 모든 취향이 정반대인 두 사람. 평균을 내면 둘 다 불만입니다. 우리는 **가장 아쉬운 사람의 만족도**를 먼저 올립니다. 경치 좋은 길은 +몇 분인지 함께. |
| 2:15–2:45 | C | 타이베이도 같은 방식 — 검증한 도시만 지원합니다. 링크 하나로 공유하면 친구 화면에서 최신 시간표로 다시 열립니다. |
| 2:45–3:00 | 마무리 | 아무도 소외되지 않는 그룹 여행, 모두의 여행. |

편집: 녹화본 A(0:15~1:40) + B + C 를 이어 붙이고 앞뒤 제목 카드만 넣으면 3분이 된다.
