# 외부인 사용 테스트 (W3 게이트) — 진행 방법과 기록

> "팀 아닌 사람에게 설명 없이 사용시킴. 여기 지적이 곧 심사위원이 볼 것." (Notion 태스크 메모)
> 대상 2명 이상 · 1인 10분 · 진행자는 **설명하지 않고 관찰만** 한다.

## 준비

- 백엔드·프론트를 띄운 PC(또는 같은 와이파이의 폰에서 `http://<PC IP>:5173` — 키 B 리퍼러 제한에
  해당 주소를 추가해야 지도가 뜬다)
- 테스트 대상에게 줄 과제 카드 1장(아래), 관찰 기록지(아래 표)

## 과제 카드 (대상에게 그대로 보여준다)

> 친구 2~3명과 파리(또는 타이베이)로 여행을 가려고 합니다.
> 이 서비스로 **모두가 만족할 만한 일정**을 만들고, 친구에게 **링크로 보내 보세요**.
> 단톡방 대화가 없으면 화면의 예시를 써도 됩니다.

## 결과 반영 규칙

- 2명 중 **1명이라도** 막힌 곳은 예선 제출 전에 문구·배치로 고친다(기능 추가 금지 — 9/20 프리즈).
- 점수·지표 해석을 못 한 항목(5번 등)은 발표 스크립트에서 반드시 설명한다.
