# 테스트용 가짜 카톡 대화 5종

`POST /api/intake/chat` 과 데모 시나리오의 입력. 모두 **창작한 가상 대화**이며 실존 인물과 무관하다.
형식은 카카오톡 PC '대화 내보내기'(`[이름] [오후 3:01] 메시지`)를 따른다.

| 파일 | 도시 | 인원 | 무엇을 검증하나 |
|------|------|------|-----------------|
| `01_paris_foodie_allergy.txt` | 파리 | 3 | **데모 메인.** must_visit(루브르), 갑각류 알레르기 → 해산물 음식점 제외, 먹방 vs 미술관 |
| `02_paris_family.txt` | 파리 | 4 | 체력 약한 구성원 → 느린 pace·이동시간 상한, 공원·카페 선호 |
| `03_paris_conflict.txt` | 파리 | 2 | 모든 축이 정반대 → **평균 대신 maximin** 이 필요한 이유(발표용) |
| `04_taipei_night_market.txt` | 타이베이 | 4 | 야시장·음식 중심, 땅콩 알레르기, 빠른 pace |
| `05_taipei_quiet.txt` | 타이베이 | 3 | "박물관 절대 안 가" → culture 카테고리 제외, 느린 pace·자연 |

각 대화에는 5축 전부에 대한 근거가 한 명 이상 들어 있고, 일부 축은 일부러 근거를 빼 두었다
(→ 신뢰도가 낮아져 후속 슬라이더 질문이 나오는지 확인).
