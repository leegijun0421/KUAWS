# 데이터

## 폴더

- `raw/` — 원본 수집 데이터. **커밋하지 않는다** (용량).
- `processed/` — 전처리 산출물, API 응답 캐시. **커밋하지 않는다.**
- `scripts/` — 수집·전처리 스크립트. **이것만 커밋한다.**

원본을 커밋하지 않는 대신, 스크립트를 실행하면 누구나 같은 결과를 재현할 수 있어야 한다.
스크립트 상단에 실행 방법과 예상 소요 시간을 주석으로 적는다.

## 캐싱 규칙

경로 API는 무료 호출 한도가 있다. **모든 응답을 `processed/cache/` 에 저장하고,
동일 파라미터는 재호출하지 않는다.** 캐시 키는 (출발 좌표, 도착 좌표, 경로 유형)으로 만든다.

호출 전 Haversine 거리로 사전 필터링하여 명백히 먼 후보는 API를 태우지 않는다.
